# No-goals (binding; the anti-patterns ATLAS rejects)

- **General reasoning / frontier benchmarks.** ATLAS competes where the verifier is hard and
  the machine is local. It does not chase agentic-general leaderboards; the architecture
  scales, the nano does not pretend.

- **Autonomous financial trading.** No ground-truth verifier exists; backtests reward-hack;
  open-sourced alpha self-destroys; latency loses to HFT. ATLAS supports financial DOCUMENT
  analysis, compliance, monitoring-with-rules and education — never autonomous order flow.

- **Self-rewriting the orchestrator.** Improvement loops target artifacts (prompts, profiles,
  LoRAs, tools) under the gate chain; the orchestrator's own code changes only through the
  same review + tests + anchors discipline as any commit.

- **Topology as gradient.** Inherited from V2.1: TDA observes (notebooks), never optimizes.

- **Unverifiable answers.** A claim that fails the composite verifier is revised or abstained —
  never emitted with confidence theater.
